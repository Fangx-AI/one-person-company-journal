# 但行好事，莫问前程，保持良好心态

> 最近这段时间，我着实被网上的洪流裹挟着，心态起了不小的波澜。

最近这段时间，我着实被网上的洪流裹挟着，心态起了不小的波澜。

其实在正式做一人公司之前，即便我是计算机专业出身，对AI行业也只停留在浅薄的认知里。对全球行业的迅猛变化、一人公司的落地逻辑，还有AI变现的种种路径，我都谈不上深入了解。

可当我开始日复一日地研究、深挖，反而愈发觉得自己渺小。

网络上有太多前辈，对商业的认知、对AI的理解、对玩法的打磨，都远在我之上。这份差距让我陷入了持续的焦虑——我太急于找到方向，太渴望看到结果，渐渐丢了「但行好事，莫问前程」的初心，哪怕心底真的热爱这个行业、热爱正在做的事，也被焦虑蒙住了几分纯粹。

这份心态的失衡，很快反映在了生活里。 这段时间下班回家，我几乎把自己关在房间六七个小时，一门心思扑在学习和钻研上，和家人的深入交流越来越少，甚至连耐心都在流失。

我一直是个看重亲情、性子温和的人，可最近和父母沟通时，语气会不自觉地烦躁，态度也少了往日的温柔，把所有精力都偏执地放在了一人公司上。

可静下来扪心自问：我到底在追求什么？ 

是财富吗？其实我并非渴求大富大贵，有房有车，有安稳体面的工作，有知心的朋友，情感生活也圆满，我想要的从来不是物质的堆砌，而是一份真正属于自己的事业，是能一直做热爱之事的踏实与自由。

可即便奔赴热爱，也不该冷落生命里最珍贵的人。家人、挚友、爱人，这些才是我生命中重于一切的存在。

或许我拼尽全力做热爱的事，初衷也是为了让他们过得更好，可更该珍惜的，明明是当下——是此刻的陪伴，是给身边人足够的耐心与温柔，而不是把焦虑化作坏情绪，留给最亲的人。

创业者本就背负着更多压力，思虑也比常人更重，但压力绝不该转嫁至亲。那是情绪的失控，更是对最亲之人的辜负。

稳住情绪、守住心性，本就是每个创业者的必修课。

往后依旧会全力以赴，但也会记得——但行好事，莫问前程。 

保持乐观，心怀热爱，对未来有信心，对自己有耐心，也对身边人，多一分温柔与珍惜。
