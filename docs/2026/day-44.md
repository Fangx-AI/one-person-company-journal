# 专注做事导致共情能力下降

> 最近我的共情能力，变得越来越差了。

最近我的共情能力，变得越来越差了。

最明显的一次，是昨天同事晚上聚餐，大家吐槽上班的各种破事。

抱怨工作太累、不想干活、被领导刁难，语气里满是疲惫和委屈。

换做以前，我或许会跟着附和，会安慰几句，会共情他们的烦躁。

但这一次，我坐在旁边，心里毫无波澜，甚至觉得：这些事，真的算事吗？

说个与大部分人都不同的观点。

对我而言，每天都一样，没有所谓的 “工作日” 和 “周末” 之分。

因为每一天，我都在工作。

甚至周末的工作时长，比工作日还要多。

我早已习惯了这种节奏，自然不会因为 “要上班” 而焦虑，也不会因为 “能休息” 而开心，情绪好像被调成了 “平稳模式”，不悲不喜，只专注于自己的事。

不只是工作上，生活里很多事情，我也渐渐失去了多余的情绪波动。

尤其是在我全身心投入一人公司、朝着超级个体目标奔跑的时候，“情绪” 这个东西，离我越来越远了。

说出来可能很多人不信，甚至会觉得我在吹牛、在凡尔赛、在装逼。

我最大的爱好，是读书和学习。

我发誓，这是真的。

我太享受学习带来的正反馈，太沉迷那种知识填满大脑的满足感了。

不管学到的知识是有用的还是暂时用不上的，是能落地的实际技能，还是只能带来精神愉悦的虚拟滋养，我都能感受到一种发自灵魂的、颤抖的开心。

这种感觉，其实从读研的时候就有了。

因为我导师放养，那个时候我超级闲。

自己一个人租房子在外面住，一天能安安静静看七八个小时的书。

没有功利心，没有目的性，就是单纯享受阅读的过程，享受走进别人的人生、汲取别人的智慧的感觉。

我常常把自己比作一块海绵，疯狂地汲取新的水分，拼命地膨胀自己。

这种学习带来的快感，极大地加快了我的成长速度。

对我来说，评判一天过得好不好、有没有意义，从来不是看我今天变得多强大，赚了多少钱。

而是看我今天有没有提升自己，有没有学到新的知识。

这，才是我每天最在意、最核心的事。

又偏题了，拉回正题。

最近有读者问我：“怎么判断自己是不是在真正专注地做一份事业？”

我给了他一个很刁钻，但很真实的角度。

当你的共情能力开始下降，大概率就是你真正沉下心来做事的时候了。

因为人在长期专注于一个目标、承受一定压力，或者需要自我保护的时候，共情能力会自动收窄。

我们把绝大部分精力，都投入到了目标、任务和自我建设上，对外界情绪的敏感度，自然会降低。

这不是冷血，也不是麻木，而是大脑的 “心理节能模式”。

自动关掉多余的情绪感知，把所有能量，都留够处理正事的精力。

以前，别人一句委屈的话、一个低落的表情，你都能立刻接住，会共情、会安慰、会代入。

现在，你没力气、没兴趣、没反应，不是不在乎，是大脑在 “省电”，在优先保护你的能量，让你能专注于自己最看重的事。

你把所有能量都锁死在了自己身上，优先完成自己的成长和目标。

我认为这就是专注做事的样子。

说完这些，还是给各位 “股东们” 汇报下今天的工作，不辜负每一份信任，也记录自己的每一步成长：

完成了采集蜂相关的万字公众号文章，把之前踩坑的经验、实操的细节，都完整梳理了下来；

花 3 个小时系统学习剪映剪辑，亲手做好了专属的开头动画和转场效果，为后续视频更新做准备；

编程推进个人品牌网站开发，域名已经在申请中，不出意外的话，这周就能正式上线，以后我的所有内容、教程、课程，都会同步到这个专属阵地；

继续测试明朝内阁管理系统，打磨细节，解决之前遇到的各种问题；

完善飞书蜂群 Agent 系统，优化采集蜂、研究蜂、审核蜂的协同逻辑，争取早日实现全自动运转。

这里重点和大家说一下，为什么我要花时间学习剪映、打磨视频质感。

因为我后续准备调整方向，做横版视频，题材是每天分享一个Vibe Coding项目，做中高质量的干货视频。

我纯口播大概做了 10 天左右，效果一直很一般。

复盘下来，问题很明显：我是半露脸（遮住眼睛），口条不算好，题材不够垂直，最关键的是，给观众带来的价值感严重不足。

因为AI知识类在口播领域很不吃香，这个领域更多的实际上是长视频和干货教程实操类吃香。

所以我决定调整战略。

从低质量的纯口播，转为中高质量的 VibeCoding 项目分享。

其实核心目的就一个，给观众提供更高的价值感和信息密度。

虽然我口播尝试失败了，但是我觉得这次尝试我收货非常非常大。

最大的收获，就是突破了自己的口播心魔。

我从来没有拍过口播，虽然长得不算丑，平时也很外向，沟通上没什么问题，但骨子里还是个 “要脸” 的人，一直不敢面对镜头。

这次拍口播，虽然遮住了眼睛，但对我来说，已经是很大的突破了。

整个过程，比我想象中顺利太多，也让我彻底克服了对镜头的恐惧，锻炼了自己面对镜头的能力，还有凭空口述、梳理思路的能力。

我很开心，也很庆幸自己迈出了这一步。

后续如果内容做的足够好，我也会慢慢把完整的自己呈现在镜头前，遮不遮眼睛，好像也没那么重要了，我现在完全可以接受了！
