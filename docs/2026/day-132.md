# 从大众心理层面剖析VibeCoding爆火原因

> 今天早上看《时间游戏》第一章，里面有一句话我印象很深：

今天早上看《时间游戏》第一章，里面有一句话我印象很深：

人相信时间是“身边风险”和“远方机会”的组合，才会觉得未来值得努力。

这句话一下子让我想到最近这一轮 Vibe Coding 的爆火。

很多人解释 Vibe Coding，都会从技术角度讲。比如大模型代码能力变强了，Cursor、Claude Code、Codex 这类工具降低了编程门槛，普通人也能靠自然语言搭网站、写脚本、做小产品。这些当然都对。

但我今天更想从另一个角度讲：Vibe Coding 真正火起来，可能不只是因为它提高了生产力，而是因为它重新给了普通人一种“未来还有机会”的感觉。

先说一个不太讨喜的判断：对大部分普通人而言，Vibe Coding 目前还没有强到“一个人随便做出一个“中等项目”的程度。（注意我说的是中等，甚至不是高等）

我自己高强度使用这些AI Agent工具，也做过网站，小程序，APP，写了很多功能。

我的真实感受是：普通人靠 AI 编程，最多最多可以做一个中等规模的项目。

那为什么 Vibe Coding 还是这么火？

我认为真正的背后驱动力，是大家身边的风险和压力变多了。

从 2021 年左右开始，地产下行的体感越来越强。房价下跌，地产链条收缩，很多人的资产预期被改变。到 2026 年，公开数据里还能看到这种压力，比如中国 70 城新房价格同比继续下跌，已经连续很多个月走弱。就业也不轻松，失业率虽然阶段性回落，但仍然维持在不低的位置。

这些数字背后对应的是很具体的心理状态：失业、找不到工作、担心收入、担心行业、担心自己以后没有位置。

这就是《时间游戏》里说的“身边风险”。

个体风险不是抽象的。

它可能是公司裁员。

可能是房子不涨了。

可能是工资停滞。

可能是年龄增长。

可能是每天刷到别人靠 AI 赚到钱，而自己不知道该怎么开始。

当一个人长期处在这种状态里，他会本能地寻找出口。

这个出口不一定马上让他变富，也不一定真的能解决所有问题，但它必须提供一点缓冲，提供一点方向，提供一点“我还能做点什么”的感觉。

Cursor、Claude Code、Codex 这类工具，正好给了这种出口。

Cursor 官方 2025 年公布过一轮融资，估值已经到 293 亿美元。后面还有媒体和市场讨论把它推到更高估值区间。一个面向开发者，甚至部分面向普通人的代码工具，可以在这么短时间内变成几十亿美元、上百亿美元级别的公司，背后当然有技术原因，但我认为也有很强的心理原因。

它给了很多不懂编程的人一个想象——我好像也能做产品了。

不是“我已经做成了”，而是“我好像也能做”。

这个“好像”就是远方机会。

你本来面对的是身边风险：就业不确定、收入不确定、未来不确定。

Vibe Coding 突然给你打开一扇门：你可以自己做网站，可以做工具，可以做 SaaS，可以做小程序，可以做自动化，可以做 AI 产品，可以一个人启动一个项目。

哪怕现实上你最后只能做出一个很小的东西，心理上它已经把你的时间打开了。

这就是 Vibe Coding 最厉害的地方。

它把不可预见的未来，从“我只能等待外界安排”，改写成“我好像能亲手做点什么”。

这就是时间被重新创造出来了。

时间不是一天 24 小时。一天 24 小时只是物理时间，是钟表时间。人真正感受到的时间，是风险和机会之间的张力。

如果身边只有风险，远方没有机会，人会绝望。

如果身边没有风险，远方到处都是机会，人会懒惰，甚至沉迷套利。

一个人愿意持续努力，往往是因为他同时感受到了两件事：身边确实有风险，但远方也确实有机会。

这就是为什么 Vibe Coding 会快速传播。

它不是单纯卖代码能力。

它卖的是一种新的“时间感”。

以前你想做一个软件产品，第一反应是：我不会编程，我没有团队，我没有钱，我没有 CTO，我是不是根本没资格开始？

现在 Vibe Coding 告诉你：你可以先试试。

你可以让 AI 写第一版。

你可以把想法变成页面。

你可以先做一个 MVP。

你可以边做边学。

你可以先不管自己是不是程序员。

这件事对很多普通人来说，心理冲击非常大。

因为它不仅降低了技术门槛，也降低了行动门槛。

当然，这里面也有幻觉。

很多人会把 Vibe Coding 想得过于简单，好像只要 Token 足够多、时间足够多，就能做出任何产品。

理论上，你可以这样幻想：如果我的时间无限，我的 Token 无限，我的模型无限强，那我是不是可以打造任何东西？

这个想象很危险，但也很强大。

危险在于，现实里你很快会遇到维护、产品判断、商业化、用户反馈、支付、安全、增长这些问题。AI 可以帮你写代码，但不能替你承受全部责任。

强大在于，它确实会激发人的主观能动性。

Token 可以估价，但希望很难估价。

一个人愿意花几百块、几千块买 AI 工具，表面上买的是模型调用，实际上买的是“我还能做出点东西”的希望。

这也是为什么 Vibe Coding 会和一人公司叙事绑在一起。

一人公司这个概念，本身也不是单纯的商业模型。

它在某种程度上也在缓解大众心理焦虑并告诉你：你不一定要进大公司，不一定要等别人给你岗位，不一定要在传统组织里寻找安全感。你可以用 AI、工具、互联网和自己的判断，构建一个小系统。

我不是说一人公司已经成熟了。

恰恰相反，我觉得当下一人公司还远远不成熟。工具链还不稳定，AI Agent 还不够可靠，普通人的产品能力和商业判断也差距很大。未来它会体系化，会成熟，但现在更多还处在野蛮生长阶段。

但它为什么仍然有吸引力？

因为它给了人一个远方机会。

而且这个机会不像考公、考研、买房、升职那样被高度制度化。它看起来更开放，更个人化，也更像一场游戏。

一个人做出来的小产品，可能现在一分钱不值。它没有收入，没有用户，没有融资，也没有什么可交易资产。但它背后代表了一种新的社会位置想象：我不再只是一个等待岗位的人，我是一个可以创造产品的人。

这个身份变化很有意思。

Vibe Coding 不是直接给你钱，也不是直接给你一个成熟公司。它更像是给你“印”出了一段新的尝试时间。

这并不等于你一定能赢。

但它把“我根本进不了场”变成了“我可以先试一局”。

大家在探索一种可能——我能不能从一个消费者，变成一个创造者？我能不能从一个打工者，变成一个拥有自己产品的人？我能不能通过 AI，把原本不属于我的能力拿到手里？

这种心理变化，才是 Vibe Coding 爆火最底层的燃料。

它把一个普通人的 Hope 拉长了。

这种 Hope 在经济低迷、就业焦虑、资产预期下降的大环境里，会变得格外有传播性。因为人越焦虑，越需要一个出口。

人越觉得身边风险逼近，越需要远方有一个机会让自己相信：我还可以努力，我还没有完全被困住。

Vibe Coding 爆火，不只是因为它能写代码。

而是因为它在一个焦虑的时代里，重新制造了“远方机会”。

写在最后，本文只是探讨心理层面，不存在任何批判。

从商业的角度讲，其实制造远方机会是一个极强的营销叙事能力。

我个人是很相信这个远方机会的，所以我每天都在努力，我也坚信这个远方机会是可以实现的，大家一起共勉。
