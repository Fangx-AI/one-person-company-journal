# AI时代，没有什么比搞好身体更重要

> 最近可以说身体达到了巅峰，协和体检基本上没问题，体脂是 12.8%。

最近可以说身体达到了巅峰，协和体检基本上没问题，体脂是12.8%

我意识到，在铺天盖地的AI焦虑洪流之下，没有什么比搞好身体更重要了。

薄肌也好，大水也罢。

AI永远是工具，以人为本才是真正的核心。

技术会不断发展，AI也会不断发展，现在任何一个普通人能享受到的现代互联网红利可能比以前的皇帝还要丰富。

活下去，健康的活下去，充分享受现代社会的便利与美好。

干净的水、健康的食物、随时可看的电影、随时可听的音乐、随时可连线的朋友，还有随时能利用AI学知识。

这些，才是真正属于我们的“时代红利”。

身体垮了，再先进的AI也救不了你；心态崩了，再多的信息也只是噪音。

所以我想劝劝大家对自己好一点，把自己养好：睡够觉、吃好饭、动一动、晒晒太阳。

睡饱之后，然后再去用AI当助手——让它帮你写、帮你查、帮你算，你则腾出时间去感受真实的风、真实的人、真实的生活。

技术再怎么变，人始终是目的本身。

把身体养扎实了，把日子过踏实了，剩下的，交给时间和技术去奔跑就好。
