# 忙碌、焦虑、专注和目标

> 国庆一眨眼就过去了。这个国庆我没有出去玩，基本上就是工作、看书、健身循环。

国庆一眨眼就过去了。
这个国庆我没有出去玩，基本上就是工作、看书、健身循环。
去年国庆我去西北玩了10天，现在想来，让我什么也不做地玩上十天，应该是做不到了，可能两三天对我来说都很困难，我会觉得我在浪费时间，浪费生命，我本应该去工作的。
但不得不说，最近真的太忙了。
最近主业由于岗位的调整，变得非常忙，副业也处于一个完全拉满的状态。
副业拉满的原因是，我想在离职前尽可能让自己强大起来，挣到更多的钱、积累更多的粉丝、接触更多的人，让自己在真正离开时能够更加从容。
所以我几乎拼尽了全力，每天保持12小时以上的工作时间。
近几个月，我几乎没有什么娱乐活动。以前我会打麻将、打游戏，也会出去和朋友打德州、参加应酬，现在几乎全都砍掉了。
我把所有时间都奉献给了AI、自媒体和健身。
说实话，我的自媒体做得好很差，原因有很多，一时半会儿也讲不完。但市场和数据一直在给我反馈，不断修正我的错误行为。渐渐地，我也找到了一点营销学和传播学的感觉。
我有盲目的信心，未来我会越来越好。
很多人问我：“鑫哥，你有没有焦虑？”
坦白来讲，我的焦虑其实很大。生活的压力、感情的压力、家庭的压力，各个方面的压力都有。
我也曾经崩溃过，有时候只是因为停不下来，实在太疲惫了。但在反复的拉扯中，我能感觉到自己的抗压能力正在不断提高。现在即使很多事情同时压过来，我也能尽量保持情绪稳定，继续工作。
唯一想和大家分享的是，在这几个月里，我的身体反而变好了。
前段时间我去协和体检，身体的各项指标都比去年更好。
我想，主要是因为我开始更加严肃地对待睡眠、饮食和运动这三件事。
这半年里，我基本稳定在晚上11点多睡觉。
我的老读者都知道，以前我写一人公司纪实，经常要到凌晨一两点才发，然后三点睡觉。现在来得及发就发，来不及发就早点睡。
倒不是我想偷懒，纯粹是因为我发现，早睡能够带来第二天更好的工作状态、精神面貌和精力。
熬夜工作本质上是一种透支，我甚至觉得，它有时候也是一种逃避和借口。
当你熬夜工作以后，或许第二天就有了借口，不再好好工作、不再好好吃饭，也不再好好健身。
饮食方面，我现在几乎不再摄入多余的糖分。
以前喜欢喝奶茶，现在也开始克制，已经喝得很少了。主食基本换成了粗粮，如果点外卖，我也会尽量选择轻食。
平时在家吃饭，我会先吃蔬菜，再吃蛋白质，最后吃米饭，这样可以让血糖更加稳定。
健身方面，我丝毫不吹牛地说，我的薄肌身材肯定比邵艾伦要好。我的体脂是12.8%，肌肉量也比他大。
我现在一周六练，有氧和无氧全部拉满。
所以这篇文章写什么呢？
我也不知道，只是想告诉大家一下我近期的状态，毕竟我们这个栏目还是个记录型的栏目嘛。
但我现在还是有个目标的，到12月31日之前，我给自己定下了一个明确的目标：全网粉丝达到10万。
现在是2万，距离目标还很远，但这就是我现阶段最想完成的一件事。
我会拼了命地去执行，一点点把这个目标做出来。
