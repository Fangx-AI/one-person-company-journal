# Hypit 一键复制任何博主的视频

> 最近有一个很火的工具叫Hypit，听说可以一键复制任何博主的视频。

最近有一个很火的工具叫Hypit，听说可以一键复制任何博主的视频。

![Hypit 一键复制任何博主的视频 图 1](../assets/day-171/image-1.png)

![Hypit 一键复制任何博主的视频 图 2](../assets/day-171/image-2.png)

它生成的不只是一条成片，而是一套可以继续修改和复用的视频 Workflow。

Hypit目前已开源，它不是 Agent，也不是视频模型，而是给 Claude Code、Codex 等 AI Agent 使用的开源视频语言和系统。

直接安装在Agent中就可以使用，即插即用。

npx skills add hypit-ai/hypit -g
