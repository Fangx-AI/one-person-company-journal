# 同行用AI赚钱，会带来多大焦虑

> 今天聊一个没有绝对结论的话题

![同行用AI赚钱，会带来多大焦虑 图 1](../assets/day-118/image-1.png)

今天聊一个没有绝对结论的话题
大家看到做AI赚钱的，会焦虑吗？
我会。
这个焦虑其实并不是羡慕别人赚了多少钱，而是焦虑反思我自己，我的方向会不会有问题，我选的赛道会不会有问题，我是不是可以过的更好呢？
这种感觉体现在同行上尤其强烈，因为他做的东西，你本来也可以做。
传统行业还好一点，AI+互联网行业我觉得这个情况还是很严重的
因为可发展的路线太多了，太多业务可以做了，真的是五花八门
如果一个人做ai互联网产业，不焦虑
那我真的佩服他，修心修到位了。
因为不管怎么做，一定会有人用户体验做的比你好，运维做的比你好，产品做的比你好，营销做的比你好，赚的钱比你多。
当你看到这些，就会开始反思和质疑自己，甚至换赛道对标。
这个时候是继续坚守自己的初心判断呢？还是应该对标换赛道呢？
这是个很综合的问题，至少我觉得很难判断。
但是夹在中间不上不下，一定是很痛苦的，要不你就坚持到底，要不你就对标抄袭到底，中间态只会越来越焦虑。
我看过一个论断，说在AI兴起的时候，不去做中转站，不去卖token，不去卖课，反而去做一些自认为很好的产品，去打磨产品，都是傻逼。
说的很好，从赚钱的角度来看，我觉得也有道理。
但是人要有自己的评价标准，什么评价标准对于自己来说是有价值的呢？
如果你的评价标准是快速赚钱，那么你就应该去对标，快速复刻，产品抄袭，卖课，你赚的很舒服，做的也很舒服，那么这就是符合你的道路。
如果你做的很痛苦，不喜欢，那么你觉得这个痛苦和赚这个钱对比的话，是否还能长期忍受呢？如果能，那做也是没有任何问题的。
我个人主要是物欲很低，其实我觉得温饱之后，其他都不是很重要，做自己喜欢的事情最重要。
包括群里人让我带他赚钱，我会分享我看到的，学到的知识。
但是我也会直说，我的赚钱能力，确实一般。
我是实话实说，因为我有时候打磨细节，一打磨就是一天，很耽误赚钱。
当然渠道还是有的，基本上现在互联网的很多产业我都能对接上，可能这也是做自媒体的一个好处，接触到很多以前看不见的东西。
可能我需要调整，可能也不需要调整，可能我现在的路是对的，也可能是错的。
但我愿赌服输。
关键还是要有一颗坚定的心呐！
