# 上线前人工检查清单

本清单用于发布前最后 10-15 分钟人工核对，避免“构建通过但线上体验异常”。

## 一、内容与链接

- [ ] 新增实录在 `/journal` 列表可见
- [ ] 新增实录详情页 `/journal/:slug` 可打开
- [ ] 实录正文排版正常，图片顺序正确
- [ ] 无明显错别字、乱码和断句问题
- [ ] 旧产品或停止维护项目没有重新出现在首页、导航或页脚入口

## 二、核心页面

- [ ] 首页 `/` 可正常打开，首屏图片正常加载
- [ ] `/journal` 可打开，列表和筛选正常
- [ ] `/journal/day-94` 等详情页可打开
- [ ] `/products` 可打开，展示内容符合当前维护状态
- [ ] `/about` 可打开
- [ ] 任意不存在路由显示 404 页面

## 三、移动端体验

- [ ] iPhone/安卓尺寸下首页无明显遮挡
- [ ] 日志列表和详情页可正常滚动
- [ ] 页面切换不卡死、无黑屏
- [ ] 导航菜单可打开和关闭

## 四、技术检查

- [ ] 已执行 `npm run check:release` 且全部通过
- [ ] 发布后 `https://fxin.cc` 能打开
- [ ] 发布后静态资源返回 200（JS/CSS/图片）
- [ ] 浏览器控制台无严重报错

## 五、安全与运维

- [ ] HTTPS 证书有效，未接近过期
- [ ] Nginx 配置无语法错误（`nginx -t`）
- [ ] 日志无连续 5xx 错误
- [ ] 本次变更可回滚，保留上一个可用版本

## 六、发布后 5 分钟回看

- [ ] 再次访问首页，确认缓存更新已生效
- [ ] 随机打开 1 篇日志检查细节
- [ ] 确认无“刚上线正常，几分钟后异常”的情况
