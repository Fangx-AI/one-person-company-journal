# 搜索引擎提交模板（可直接复制）

用于上线后快速提交站点与 sitemap。

## 站点基础信息

- 站点地址：`https://fxin.cc`
- Sitemap：`https://fxin.cc/sitemap.xml`
- Robots：`https://fxin.cc/robots.txt`

## Google Search Console 提交模板

1. 打开：<https://search.google.com/search-console>
2. 添加资源（URL 前缀）：`https://fxin.cc`
3. 完成验证（推荐 DNS）
4. 进入 `Sitemaps`，提交：`https://fxin.cc/sitemap.xml`
5. 记录提交时间与状态

记录格式：

```text
平台：Google Search Console
提交时间：YYYY-MM-DD HH:mm
Sitemap：https://fxin.cc/sitemap.xml
状态：Submitted / Success / Error
备注：-
```

## 百度搜索资源平台提交模板

1. 打开：<https://ziyuan.baidu.com/>
2. 添加站点并验证
3. 在“链接提交 / Sitemap 提交”中提交：`https://fxin.cc/sitemap.xml`
4. 记录提交时间与状态

记录格式：

```text
平台：百度搜索资源平台
提交时间：YYYY-MM-DD HH:mm
Sitemap：https://fxin.cc/sitemap.xml
状态：Submitted / Success / Error

```
