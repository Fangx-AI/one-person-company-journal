# 移动端回归检查清单

每次上线后至少抽查一次 iPhone 视图和安卓视图。

## 一、首页（/）

- [ ] 首屏正常加载，无黑屏
- [ ] 背景视频可播放，无明显卡顿
- [ ] 顶部导航可点击
- [ ] 跳转到实录、资源页面正常

## 二、实录列表（/journal）

- [ ] 列表页可打开，卡片正常渲染
- [ ] 卡片点击弹窗正常打开与关闭
- [ ] “打开详情页”可跳转到 `/journal/:slug`
- [ ] 详情页中的上一篇/下一篇跳转正常

## 三、资源页（/resources）

- [ ] 分类切换正常
- [ ] 卡片点击弹窗正常
- [ ] 资源链接点击可打开
- [ ] 提示词卡片复制按钮可用

## 四、基础技术项

- [ ] `https://fxin.cc/robots.txt` 可访问
- [ ] `https://fxin.cc/sitemap.xml` 可访问
- [ ] 首页和详情页无明显布局错位
- [ ] 页面滚动流畅，无卡死
