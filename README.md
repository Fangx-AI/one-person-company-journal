## 说明

这个仓库包含个人博客网站源码，以及公开整理后的一人公司纪实数据。

- 文章数据：`public/data/journal-entries.json`
- 单篇数据：`public/data/journal/`
- 网站源码：`src/`
- 内容脚本：`scripts/`

历史文章保留当时的表达和项目状态。部分旧产品可能已经停止维护，但仍然是这段记录的一部分。

## 本地运行

```bash
npm install
npm run dev
```

发布前检查：

```bash
npm run check:release
```
